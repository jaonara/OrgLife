# College logos

The current college logos are mapped by filename:

- CCS: `CCS logo.jpg`
- COE: `COE logo.jpg`
- CBA: `CBA logo.jpeg`
- CED: `CED logo.jpg`
- CAS: `CAS logo.jpg`
- COC: `COC logo.jpg`

The images are displayed with `object-fit: contain` so each full logo remains
visible. Keep the filenames unchanged, or update the corresponding mapping in
`client/src/App.jsx` when replacing an image.
